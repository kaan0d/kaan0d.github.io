Synopsis

Hi, I'm Kaan. Computer engineer interested in the defense industry, with a BSc from Gaziosmanpaşa University (GPA 3.45/4.0) and an Erasmus term at Kielce University of Technology in Poland.

I work on a hospital information system with about 3,000 users, where rewritten Oracle SQL queries cut a typical report load from over 30 seconds to 6.5 seconds. Outside work I write things from scratch: a packet analyzer and IDS in Python, a 2D physics engine in TypeScript, and full-stack and desktop apps for retail businesses, with React on the frontend and Python desktop tools backed by SQL. Most recently I built tls-peek, a Python tool that decrypts the HTTPS traffic of one chosen Windows program and shows it in a local web UI, with a capture certificate that is removed when the capture stops. I've also completed the three Cisco CCNA courses.

I like owning a project end to end, from the database up to the interface, rather than one slice of it.

04Solo · open source · released

HTTPS Inspector for Windows

tls-peek

Shows the HTTPS requests one Windows program sends, in a local web UI. Built on mitmproxy's local mode and the WinDivert driver, so it works on programs that ignore the system proxy, and each capture gets its own CA that is removed on stop; hosts that refuse it pass through so the program keeps working. Adds intercept and rewrite rules, TLS and timing details, 39 passive security checks on requests and responses, live event streams and an API map with OpenAPI export; CI tests it on Windows, clicks through the UI in Chrome, and builds an exe and a zip.

  • Python
  • mitmproxy

Packet Analyzer / IDS

Sentinel

Packet analyzer and intrusion detection system in pure Python, with hand-written parsers from Ethernet to TLS ClientHello and no runtime dependencies. It reassembles TCP streams, filters with its own language, captures live on Linux and Windows, and detects port scans, SYN floods, ARP spoofing and DNS tunneling. On 14.6 s of a 1 Gbps backbone it found the same 376 scanning sources as an independent tshark recount.

Game AI / Pathfinding

Environment-Aware Pathfinding

Game AI pathfinding that treats walls as a decision: a planner prices every wall in seconds and picks the target and route by total time, and squads share one plan limited by the attack positions around a wall. A PixiJS demo runs a classic AI and the new planner side by side, with an editor, nine maps and a debug view. On 200 random maps the pick is within 5% of the best plan on 199 or 200 of them, and the time estimate is off by about 1% on average.

2D Physics Engine

Impulse

2D rigid body physics engine in TypeScript with no physics libraries: SAT collision for circles, boxes and convex polygons, a warm-started sequential-impulse solver, sleeping, continuous collision and five joint types.
